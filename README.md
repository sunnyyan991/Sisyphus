# 诸神的差事

> 第一次看这个项目？先读 [docs/brief.md](docs/brief.md)：概念、基调、每集玩法和已知问题都在里面。

一组荒诞短剧。你是奥林匹斯新录用的公务员，每一集被调去一份新的天罚岗位。

在线游玩：https://sunnyyan991.github.io/Sisyphus/

| 集 | 标题 | 岗位 | 目录 |
|---|---|---|---|
| 1 | 西西弗斯再来一次 | 踹石神 | `sisyphus/` |
| 2 | 普罗米修斯，四种说法 | 啄肝鹰（外包） | `prometheus/` |
| 3 | 电车又来了 | 扳道工 | `trolley/` |

根目录 `index.html` 是游戏主界面，可以选择差事和章节。每一集都是单个 `index.html`，支持用 `#ch3` 这样的链接直接进入某一章。点屏幕或按空格游玩。

灵感来自希腊神话、加缪《西西弗斯神话》、卡夫卡《普罗米修斯》与菲利帕·福特的电车难题。
