# 诸神的差事：项目说明

这份文档写给第一次接触这个项目的人（或 AI），用来快速了解它是什么、为什么这样做，以及目前还有哪些问题。代码在 `develop` 分支上，`main` 分支目前只有最早的单集版本。

## 一句话

一组网页互动短剧。玩家是奥林匹斯新录用的公务员，每一集被人事部的赫尔墨斯调去一份新的"天罚岗位"，执行一份永远做不完的工作。

## 文件结构

每个页面都是一个独立的 `index.html`，没有构建步骤，也不依赖外部库（只从 Google Fonts 加载字体）。

## 基调

用打工人的口吻，一本正经地讲神话和哲学里的永恒惩罚。

1. **荒诞的事，用上班的语言说。** 宙斯看周报、岗位外包、受罚者成立工会、抢论文一作。
2. **一句话一个笑点，不解释，不用感叹号。** 例如"预计处理时长：永恒。""他把杯子摔了。金的。"
3. **没人真的受伤，讽刺对准制度，不对准角色。** 被电车撞的人会站起来说"没事！思想实验！"
4. **结尾留一点真心，但不点破。** 每集都轻轻落在"无意义的劳动"上，玩家最后会发现自己也在这个循环里。

画面统一用古希腊黑绘陶罐风格：陶土橙配墨黑剪影，加骨白色的刻线和回纹边框，用 Canvas 绘制。

## 系列框架

- 赫尔墨斯是贯穿全系列的人事，每集开头给玩家调岗，接上一集的结局。
- 每集是一个线性故事，分 5 到 6 章，每章流程是：章节卡 → 几句对话 → 一段操作。
- 不设"游戏结束"。失败会被处理成笑点（例如"检测到违规登顶，已回滚"），然后故事继续。
- 每集通关后可以进入下一集；主界面会记录看过的章节，链接末尾加 `#ch3` 这样的锚点可以直接进入某一章。

## 各集概要

### 第一集：西西弗斯再来一次（岗位：踹石神）

参考：加缪《西西弗斯神话》。

- **核心玩法**：他推石头上山，你点击把石头踹下去。离山顶越近再踹，分越高；让他推到山顶会被"回滚"。
- **章节**：入职 → 绩效（引入"绝望指数"KPI）→ 石头先生（他在石头上画了一张脸）→ 罢工（他坐着不推，你踹也没用）→ 一本书（天上掉下《西西弗斯神话》，他决定"不能让读者失望"，开始变得幸福）→ 调岗（角色反转：你推石头，他站在山顶踹）。

### 第二集：普罗米修斯，四种说法（岗位：啄肝鹰，外包）

参考：卡夫卡的短篇《普罗米修斯》。原文列出了"四种传说"，而网上有读者指出那其实是同一件事的四个阶段，这个争论被写进了剧里，成了笑点。

- **核心玩法**：他的肝会慢慢长满，长满时点击啄一口；啄早了算返工，等太久会过期。
- **章节**：
  - 序章 · 轮岗
  - 锁链：他会预言你怎么啄，你可以故意不照做
  - 岩石：每啄一口，他就陷进山里一点
  - 遗忘：界面也跟着失忆，标签变成问号
  - 疲倦：点击之后，鹰先打个哈欠才动
  - 尾声 · 山：所有角色淡出，只剩那座山

### 第三集：电车又来了（岗位：扳道工）

参考：菲利帕·福特 1967 年提出的电车难题，以及它在网上的各种 meme 变体。这一集刻意每章换一种玩法，避免重复。

| 章节 | 玩法 |
|---|---|
| 标准版 | 在电车经过道岔前决定扳不扳 |
| 天桥 | 对话选择，三选一 |
| 论文 | 道岔网络谜题，分三步升级：静态 → 电车已在行驶 → "论文志愿者"会跑向你指的轨道，必须最后一刻再扳 |
| 多轨漂移 | 三条轨道换道躲人 |
| 环线 | 拉杆其实没接上；最后玩家自己站在轨道上 |

顶部有一条"立场"条（功利 / 第三条路 / 义务），结局按你的选择给出称号。

## 已知问题与改进方向

以下来自一次完整试玩后的设计分析，按优先级排列。

1. **电车第四章没有兑现"多轨漂移"的梗。** 电车从来没有同时骑在两条轨上，只是普通的换道躲避。
2. **分数系统没有后果。** 三集都有绩效、KPI、立场，但几乎不影响剧情。建议每章结尾加一份"宙斯周报"，针对玩家的真实数据点评。
3. **普罗米修斯的玩法最单薄。** 后三章只换了画面，没换操作。啄的反馈也比踹石头弱。
4. **有死时间。** 西西弗斯每轮下山要等 2 到 3 秒，共 14 轮。普罗米修斯"遗忘"章有 11 句连续对话。
5. **几处文案和设计需要修。**
   - 电车谜题第二步的空轨道上直接标着"空"字，降低了难度。
   - 电车第二章三个选项里有两个通向同一个结局。
   - 电车第五章"杆没接上，但赫尔墨斯跟着你的杆手动扳"的包袱自相矛盾。
6. **基调有偏差。** 普罗米修斯偏文学、偏冷；电车偏网络 meme。两集都离第一集的"职场冷面喜剧"有些远。
7. **角色反转结尾用了两次**（第一集和第三集），继续用会变得可预测。

## 想听到的意见

- 好不好玩：操作和笑点是否咬合，哪里让人只想按"下一步"。
- 节奏：对话和操作的比例，每章的长短。
- 文案：哪些台词好笑，哪些在解释笑话，哪些偏离了基调。
- 下一集该做什么题材：倾向于网上流行的哲学或神话梗。
